## ✨ 核心特性

- 🎙️ **地道港式發音**：支持港式粵語自然口語 TTS，九聲六調精準注音與標點停頓智能切句；
- ☕ **香港生活實用場景語料**：茶餐廳、地鐵出行、租房租約、看診就醫等 14 類真實情境會話；
- 🎧 **磨耳朵連續播放模式**：支持背景連播、記憶斷點續播、粵普對照與隨身聽練耳；
- 🚀 **智能 OTA 熱更新**：語料與詞條擴充自動在線檢測，右上角浮動通知一鍵熱更新，無需反覆重裝。
